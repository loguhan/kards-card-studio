## 0. 结论：为什么现在不触发

游戏里 **52 张伏击卡，每一张**的 ubergraph 都调用 `ShouldGotchaTrigger`：

```
card_event_interception   (英国1K) Array_Get, Array_Length, BooleanAND, EqualEqual_ByteByte,
                                  GotchaTriggered, Greater_IntInt, IsOrder, IsValid, ShouldGotchaTrigger
card_event_foiled_plans   (德国1K) BooleanAND, DamageCard, EqualEqual_ByteByte, GetLocationCardBySide,
                                  GetOppositeSide, GotchaTriggered, IsOrder, ShouldGotchaTrigger,
                                  getTotalKreditCost
card_event_ultra          (英国3K) BooleanAND, DrawCardsFromDeckBySide, GotchaTriggered, IsOrder,
                                  NotEqual_ByteByte, ShouldGotchaTrigger
card_event_careless_talk  (德国1K) BooleanAND, DamageCard, GotchaTriggered, IsLocatedOnBoard, IsUnit,
                                  ShouldGotchaTrigger
card_event_stranglehold   (德国1K) BooleanAND, GetKreditsBySide, GetOppositeSide, GiveKreditsBySide,
                                  GotchaTriggered, IsUnit, Multiply_IntInt, ShouldGotchaTrigger
```

`ShouldGotchaTrigger(UBaseCardObject* triggerCard, bool& shouldIt)` 是
`UBaseCardObject` 上的 **`BlueprintNativeEvent`** —— 每张伏击卡都要**覆写它**。

**我们的卡没有覆写 → 所以不触发。**
而且 `KardsCardBuilder` 目前只支持**事件图**，根本无法覆写 `BlueprintNativeEvent`
（覆写要走**函数图**）。这是工具链缺口。

## 2. 触发链路

```
[我方] 打出本卡
   └ PlayCardDirectlyFromHand(card)
       └ card.gotchaActivated = max(同阵营场上伏击卡的 gotchaActivated) + 1   ← 布防
       └ 卡留在场上

[敌方] 从手牌打出任意卡
   └ BP_CardFunctions.CardPlayedFromHand(cardPlayed)
       ├ GetActiveGotchasOrdered(ids)   过滤: IsGotcha(card) AND gotchaActivated > 0
       └ for each id:  card.OnOtherCardPlayedFromHand(cardPlayed)      ★ 入口
```

## 4. 效果流程

### 4.1 `ShouldGotchaTrigger`（函数图，覆写 BlueprintNativeEvent）

```
ShouldGotchaTrigger(triggerCard: BaseCardObject, out shouldIt: bool):
    cost = triggerCard.getTotalKreditCost()
    shouldIt = triggerCard.IsOrder()
               AND triggerCard.side == self.GetOppositeSide()
               AND cost > 0
```

### 4.2 `OnOtherCardPlayedFromHand`（事件图）

```
OnOtherCardPlayedFromHand(cardPlayed):
    if (ShouldGotchaTrigger(cardPlayed)):
        cost = cardPlayed.getTotalKreditCost()

        // ① 反制掉原指令
        cardFunction.GotchaTriggered(Self, Self.CardID, true, false, stopped)

        // ② 从全卡池挑花费相近的指令
        pool = cardFunction.GetAllActiveStaticCards(false, false)     // TArray<UBaseCardObject*>
        candidates = []                                               // 成员变量 TArray<UBaseCardObject*>
        foreach card in pool:
            c = card.getTotalKreditCost()
            if card.IsOrder()
               AND card.faction == Self.faction
               AND c >= cost - 1 AND c <= cost + 1
               AND card.Name != Self.Name:                            // 别选到自己
                candidates.Add(card)

        n = candidates.Length()
        if n > 0:
            idx = cardFunction.RandomIntFromRangeWithStream(0, n - 1)
            target = candidates[idx]
            targetName = target.Name                                  // Name 属性

            // ③ 转换
            ids = [cardPlayed.CardID]
            cardFunction.ConvertCard(ids, Self.CardID, targetName, 0, false, newIds)

            // ④ 可观测点
            cardFunction.AddToBattleLog(Self.CardID, Self.CardID, false, true)
```
