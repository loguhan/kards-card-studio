## 卡面

> 敌方使用指令时，先将其转换为 1 张花费相近的指令。

风味文字：「命令是向那边开炮……那边。」

## 蓝图结构（EventGraph，35 个节点，0 error / 0 warning）

```
OnOtherCardPlayedFromHand(cardPlayed)
└─ if (cardPlayed.IsOrder())
   └─ tmp_cost = cardPlayed.getTotalKreditCost()
      └─ if (tmp_cost > 0)
         ├─ tmp_target = 花费相近的苏联指令名
         │    cost<=1 → card_event_comrades
         │    cost==2 → card_event_assault
         │    cost==3 → card_event_night_witches
         │    否则     → card_event_arctic_convoy
         ├─ Self.cardFunction.GotchaTriggered(Self, Self.CardID, true, false, out tmp_stopped)
         ├─ tmp_ids = MakeArray(cardPlayed.CardID)
         └─ Self.cardFunction.ConvertCard(tmp_ids, Self.CardID, tmp_target, 0, false, out tmp_newIds)
```

每个节点都是编辑器里真实可打开、可拖拽的 K2 节点
（`K2Node_Event` / `IfThenElse` / `CallFunction` / `VariableGet` / `VariableSet` /
`MakeArray` / `Self`），不是字节码拼接。

## 依据（都是实测，不是猜）

* `OnOtherCardPlayedFromHand(UBaseCardObject*)` 是
  `UFUNCTION(BlueprintCallable, BlueprintImplementableEvent)` —— 所以用**事件图**覆写。
* `IsOrder` / `getTotalKreditCost` 反射结果是 **pure**（`-Mode=Dump` 实测），
  所以能当表达式用；`GotchaTriggered` / `ConvertCard` 在 `ACardFunctionsStub` 上是
  **impure**，只能当语句调。
* `GotchaTriggered(card, instigatorID, stopFurtherCardActions, skipDiscardingOrder, out qqq)`
  的第一个参数是**伏击卡自己**（反编译 `BP_CardFunctions_GotchaTriggered`：
  `TmpGotcha = card; TmpGotcha.gotchaActivated = 0; TmpGotcha.enterPlayOnTurn = GetTurnNumber()`）。
* `ConvertCard(CardIDs[], instigatorID, convertToCardName, convertIntoCardID, skipTrigger, out newCardIDs)`
  的 `CardIDs` 是要被转换的运行时卡 ID 列表（反编译里对它做 `Array_Length` / `Array_Get`）。
* `cardFunction`（`ACardFunctionsStub*`）由 `BP_CardFunctions_CreateCardObject` 在造卡时写入，恒非空。
* 花费表：`_work\orders\` 里 17 张苏联指令 `.uasset` 实测。
